# 📚 Python Library Management System

A command-line Library Management System built with Python using Object-Oriented Programming (OOP) and file handling. This application helps users manage books by adding, viewing, searching, issuing, returning, and deleting book records.

---

## ✨ Features

- ➕ Add Book
- 📖 View Books
- 🔍 Search Book
- 📕 Issue Book
- 📗 Return Book
- ❌ Delete Book
- 💾 Store book records using a text file

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- File Handling

## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/karangiri07/python-library-management-system.git
```

### Navigate to the project

```bash
cd python-library-management-system
```

### Run the application

```bash
python main.py
```
